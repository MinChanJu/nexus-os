# 웹 기반 OS 프로젝트 (NexusOS)

## 개요

이 프로젝트는 웹 브라우저에서 실행되는 운영 체제(OS)를 개발하는 것을 목표로 합니다. 사용자는 웹 브라우저를 통해 다양한 애플리케이션을 실행하고, 파일을 관리하며, 시스템 설정을 조정할 수 있습니다.

## 주요 기능

- **파일 관리**: 파일 업로드, 다운로드, 삭제 및 폴더 생성 기능
- **애플리케이션 실행**: 텍스트 편집기, 이미지 뷰어, 미디어 플레이어 등 다양한 웹 애플리케이션 지원
- **사용자 인터페이스**: 드래그 앤 드롭, 창 크기 조절, 다중 창 관리 기능
- **시스템 설정**: 테마 변경, 알림 설정, 사용자 계정 관리

## 기술 스택

- 풀스택: Next.js, React, TypeScript
- 스타일링: Tailwind CSS
- 상태 관리: zustand
- 빌드 도구: Vercel
- 인증: NextAuth.js
- 패키지 매니저: pnpm

## 시작하기

### 사전 요구사항

- Node.js 20 이상
- pnpm 10 이상

### 설치

```bash
# 의존성 설치
pnpm install
```

### 개발 서버 실행

```bash
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 결과를 확인하세요.

### 기타 명령어

```bash
# 코드 포맷팅
pnpm format

# 린트 검사
pnpm lint

# 프로덕션 빌드
pnpm build

# 프로덕션 서버 실행
pnpm start
```
